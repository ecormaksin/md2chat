# MD2Chat — Chrome Web Store listing description

## Short description (up to ~132 characters)

Write Markdown, paste real Slack formatting. A side panel that stays open while you switch tabs — no sign-up, nothing sent anywhere.

## Full description

Markdown doesn't render as formatting when pasted into Slack — `**bold**`, `# headings`, and
`[links](...)` show up as literal punctuation instead. This extension converts it for you without
leaving your browser.

Click the toolbar icon to open the side panel. Type or paste your Markdown on one side, watch a
live preview update as you type, then click the copy button and paste directly into your message
composer — bold text, clickable links, and bulleted lists come through as real formatting, not
asterisks and brackets.

**Why the side panel instead of a popup?**
A popup closes the instant you click away from it — exactly what happens the moment you switch
tabs to paste. The side panel stays docked open across tab and window switches, so it's still
there when you come back for the next paragraph.

**What it does:**
- Converts Markdown to `mrkdwn` markup and to paste-ready rich text, live as you type.
- "Copy for Slack" copies both a rich-text version (for pasting with formatting intact) and a
  plain `mrkdwn` fallback.
- "Copy mrkdwn" copies just the raw markup, if that's what you need instead.

**What it doesn't do:**
- No sign-up, no account, no server round-trip.
- No access to any web page's content — this extension never reads or modifies the sites you
  visit.
- No data collection of any kind. See the linked privacy policy.

Everything runs locally, entirely inside the side panel.
